# Skills provenance

The skills in this directory are imported from the Nous Research
Hermes Agent project (https://github.com/nousresearch/hermes-agent),
which is released under the MIT License — see LICENSE-hermes-agent.
Each skill also declares its license in its SKILL.md frontmatter.

They follow the open agent-skills SKILL.md standard. Some reference
Hermes-specific tooling and may need adaptation for Koda.
